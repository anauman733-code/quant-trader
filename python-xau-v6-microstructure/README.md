# XAU Python V6 — microstructure edge research

Research-only engine for sub-second to 3-second XAUUSD.a edge discovery. It evaluates 0.5s, 1s, 2s and 3s horizons using quote/tick microstructure features, strict chronological train/validation/holdout splits, executable bid/ask labeling, commission estimates, and one-position-at-a-time validation screens. It does not place trades.
